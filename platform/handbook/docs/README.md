# Go Product Platform — руководство по архитектуре и разработке с ИИ

**Версия 17.0 · 21 ноября 2026 · Go-first · Модульный монолит · LOCAL-NATIVE / Приоритет VM · Навыки агентов**

Это целевой технический стандарт для разработки бизнес-приложений с помощью AI-агентов. Документ описывает решения, границы применимости, проверяемые инварианты и готовые примеры. Руководство разбито на тематические документы: каждый содержит YAML frontmatter с навигацией (`up` / `prev` / `next`), а этот файл служит оглавлением и картой перекрёстных ссылок.

> **Ключевое решение.** Go — основной язык бизнес-логики на сервере и desktop. React + TypeScript — основной Web/UI слой. Desktop — Wails 3. Для мобильных устройств сначала проверяется Wails 3, а при недостаточной зрелости создаются нативные SwiftUI/UIKit и Kotlin/Jetpack Compose клиенты. PostgreSQL и Docker Compose остаются стандартными опорами, а IdP, S3 и OpenBao подключаются по требованиям и при наличии корпоративных общих сервисов.

**Нормативное дополнение v17:** [SDD для агентов](19-agent-sdd.md) и [контракт артефактов](20-artifact-contract.md). При различии процесса с историческими главами применяется v17.
