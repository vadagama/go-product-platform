# Установка платформы и жизненный цикл навыков

Платформа не имеет исполняемого установщика: установка — это копирование
Markdown-навыков из доверенного клона в глобальные каталоги. Все дальнейшие
действия агент выполняет по документам платформы.

## Глобальная установка (один раз)

Попросите агента: «Установи навыки Go Product Platform глобально из этого клона».
Агент по [инструкции операций](../skills/go-platform-bootstrap/references/commands.md):

1. Подготавливает переносимый набор по разделу ниже в `~/.agents/` и
   `~/.claude/` из одной согласованной ревизии платформы.
2. Проверяет ссылки и наличие материалов в обоих установленных наборах,
   не полагаясь на доступность исходного клона.
3. Сообщает, какие каталоги созданы, и предлагает перечитать список skills или
   перезапустить агент ADE.

Затем откройте целевой Git-продукт и вызовите
`/go-platform-bootstrap Подготовь этот проект к разработке`. Агент проведёт
опрос в чате. Первый вопрос — «С чего вы хотите начать?»: подготовить техническую
основу без описания продукта, описать идею несколькими предложениями или разобрать
готовые требования из документов и ссылок. Для готовых требований агент сначала
показывает своё понимание и получает подтверждение пользователя. Затем все пути
продолжаются одинаково: целевые приложения → стек/окружение → дополнительные
возможности → инвентаризация → итоговый план → установка и проверки. Пользователь
не вводит команды и не выбирает технические имена профилей.
В Codex используется `$go-platform-bootstrap` или выбор скилла; slash-вызов
доступен только в поддерживающих его ADE.

## Переносимый набор платформы

Одинаковая структура применяется глобально (`~/.agents/`, `~/.claude/`) и
в продукте (`.agents/`, `.claude/`). Ниже `ROOT` означает один из этих каталогов.

| Источник в клоне | Назначение |
|---|---|
| `README.md`, `CHANGELOG.md`, `addendum.md`, весь `platform/` | `ROOT/references/go-product-platform/`, с сохранением дерева клона |
| `platform/skills/go-platform-bootstrap/` | `ROOT/skills/go-platform-bootstrap/` |
| `platform/project-skill-templates/go-project-platform-manager/` | `ROOT/skills/go-project-platform-manager/` |

Снимок содержит handbook, constitution, шаблоны, инструкции и исходные навыки.
Не копируйте `.git/`, временные файлы и секреты. Не используйте абсолютные пути
к исходному клону или симлинки: проектный набор должен работать после checkout
на другой машине. При копировании из глобального набора берите исходные навыки
из его снимка `references/go-product-platform/`, а не уже преобразованные копии.

В снимке ссылки остаются исходными. В двух каталогах `ROOT/skills/` агент
пересчитывает относительные пути в Markdown-ссылках и путевых полях frontmatter:

1. Разрешить путь относительно исходного файла в клоне или снимке.
2. Если цель внутри одного из двух устанавливаемых навыков, использовать её
   новое расположение в `ROOT/skills/`; иначе — в `ROOT/references/go-product-platform/`.
3. Записать относительный путь от установленного файла к установленной цели,
   сохранив фрагмент `#…`. Внешние URL, ссылки только на якорь и ID не менять.

Например, ссылка bootstrap `../../templates/` становится
`../../references/go-product-platform/platform/templates/`, а ссылка из его
`references/product-setup.md` на `../../../templates/engineering-workflow.md` —
`../../../references/go-product-platform/platform/templates/engineering-workflow.md`.

После копирования проверить все локальные ссылки и якоря в установленном наборе,
включая handbook и шаблоны. Проверить равенство наборов `.agents` и `.claude`.
Ревизию снимка и обоих навыков записать в реестр продукта; для глобальной установки
без продукта — в отчёт установки с SHA. Не приписывать грязному клону чистый SHA:
согласовать зафиксированный снимок либо явно записать SHA базы и локальный diff.
Существующие пользовательские изменения не перезаписывать; обновление снимка и
навыков согласовывать вместе. Проектный снимок хранится в Git и не зависит от глобального.

## Основной интерфейс пользователя: разговор на естественном языке

После глобальной установки достаточно одного запроса в продуктовом репозитории:
«Подготовь этот проект к разработке» с вызовом `go-platform-bootstrap`. Остальные
параметры агент выясняет через [опросник](../skills/go-platform-bootstrap/references/questionnaire.md),
не просит пользователя ничего выполнять вручную.

При первоначальной настройке агент читает навык `go-platform-bootstrap`
(`~/.agents/skills/go-platform-bootstrap/SKILL.md` после глобальной установки),
а для уже настроенного проекта — управляющий навык
`.agents/skills/go-project-platform-manager/SKILL.md`. Перед любыми глобальными
проверками, установками или обновлениями он должен запросить разрешение.

## Разрешения и границы

- `~/.agents/skills` и `~/.claude/skills` — глобальные каталоги пользователя;
  изменения только после явного согласия.
- Состав набора продукта отслеживается в реестре `docs/agent-skills.md`
  и копиях в `.agents/`, `.claude/` под Git; проектные версии имеют приоритет
  и не меняются от глобальных обновлений.
- Работа в worktree не требует установки: проектные материалы приходят из Git;
  каждое дерево само строит генерируемые артефакты (например, граф graphify).
- Скрипты сторонних навыков никогда не запускаются автоматически.

## Обновления

Проверка выполняет только чтение: сравнение ревизий реестра с источниками.
Применение — отдельная операция, требующая одобрения; прежние снимки сохраняются
для восстановления. Orca и Graphify используют собственные официальные механизмы
обновления. Новые имена навыков добавляются правкой
[каталога источников](../skills/go-platform-bootstrap/references/skill-sources.md),
а не непроверенным автоматическим поиском.

## Проектный набор агентных материалов

После согласования списка (навыки, агенты, референсы, пути, ревизии) агент
копирует материалы в `.agents/` и `.claude/` продукта и фиксирует набор в реестре.
Эти копии хранятся в Git и имеют приоритет над глобальными. Корневые AGENTS.md
и CLAUDE.md требуют на русском соблюдать software-development-workflow.
MANUAL.md содержит настройку, окружение, запуск и проверки конкретного продукта.
