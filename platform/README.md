# Go Product Platform v15 — локальные материалы проекта

Создаются в `.go-product-platform/` для каждого рабочего дерева. Каталог игнорируется Git, не содержит копий общих или глобальных навыков и включает один проектный **управляющий навык** с инструкциями для работы через агента ADE.

| Путь | Описание |
|---|---|
| `handbook/` | Тематические документы руководства (`docs/`) и автономная HTML-сборка (`index.html`) |
| `constitution.md` | Инженерные инварианты проекта |
| `profiles/` | Доступные локальные профили платформы |
| `manifests/` | Курируемый каталог глобальных навыков (только метаданные) |
| `active-global-skills.md` | Имена навыков, выбранных для этого продукта; не копии навыков |
| `project-skills/go-project-platform-manager/SKILL.md` | Локальный порядок настройки и обновлений через агента |
| `references/` | Документация и ссылки на каталоги |
| `graphify/out/` | Результаты построения графа для конкретного рабочего дерева |
| `tools/gpp.py` | Локальный исходный код CLI для восстановления; предпочтителен `~/.local/bin/gpp` |

Глобально установленные навыки совместно используются через `~/.agents/skills/` и `~/.claude/skills/`. Версии их исходников зафиксированы в `~/.agents/go-product-platform/global-skills.lock.json`.

**Попросите агента:** «Покажи активные навыки этого проекта и предложи обновления, но ничего не устанавливай без моего подтверждения». Агент должен прочитать `AGENTS.md`, затем `project-skills/go-project-platform-manager/SKILL.md`.

Активация для проекта хранится в отслеживаемом файле `go-product-platform.lock.json`. Ни инициализация проекта, ни настройка рабочего дерева не разрешают установку, обновление или сканирование глобальных навыков. Пользователь одобряет глобальные изменения отдельно.
