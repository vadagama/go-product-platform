# Go Product Platform — материалы платформы

Платформа — коллекция Markdown-документов с YAML frontmatter, связанных
гиперссылками. Исполняемых скриптов нет: настройку и сопровождение выполняет
агент по документам, подтверждая план у пользователя. Состав набора продукта
фиксирует отслеживаемый реестр `docs/agent-skills.md`.

| Путь | Описание |
|---|---|
| `skills/go-platform-bootstrap/` | Навык начальной настройки: SKILL.md + references (опросник, подготовка продукта, источники навыков, операции агента, примеры AGENTS.md/CLAUDE.md) |
| `project-skill-templates/go-project-platform-manager/` | Шаблон проектного управляющего навыка: порядок установки, выбора и обновления набора через агента |
| `templates/` | Шаблоны init-документов и пример CI; состав и границы — [templates/README.md](templates/README.md) |
| `handbook/` | Руководство (`docs/`) — канонический Markdown-источник |
| `references/` | Инструкции установки платформы, ADE и canvas |
| `constitution.md` | Инженерные инварианты проекта |

Глобальные каталоги `~/.agents/skills/` и `~/.claude/skills/` служат источниками.
Согласованный набор копируется в `.agents/` и `.claude/` продукта, включая агентов
и референсы. Проектные версии имеют приоритет; их источники и ревизии фиксируются
в реестре продукта.

**Попросите агента:** «Покажи активные навыки этого проекта и предложи обновления, но ничего не устанавливай без моего подтверждения». Агент должен прочитать `AGENTS.md`, затем `.agents/skills/go-project-platform-manager/SKILL.md`.

Ни настройка продукта, ни работа в worktree сами по себе не разрешают установку,
обновление или сканирование глобальных навыков. Пользователь одобряет глобальные
изменения отдельно.

## Разработка продукта по SDD

Перед любой фичей читать отслеживаемый `docs/workflow.md` в docs/ продукта. Спецификации и архитектура также находятся в `docs/` продукта, а не здесь.
Порядок: SPEC → design → plan → tasks → реализация со свежими проверками →
независимое ревью → готовность. Артефакты — обычный Markdown с YAML frontmatter,
дисциплину обеспечивают workflow.md, ревью и Git.
Полный регламент: `handbook/docs/19-agent-sdd.md` и `20-artifact-contract.md`.

Graphify входит во все профили по умолчанию, включая custom; отсутствующий навык
устанавливается глобально при настройке. Для UI доступна опциональная установка
app-canvas по [инструкции canvas](references/canvas-installation.md).
