# Реестр агентного набора продукта

Единственный источник истины о составе навыков, агентов и референсов продукта
(замена lock-файла). Таблица ведётся агентом при каждой установке или обновлении
набора; изменения проходят согласование в чате. Проектные копии в `.agents/` и
`.claude/` имеют приоритет над глобальными; источник и ревизия каждой копии — здесь.

В каждой строке фиксируйте точные пути, источник и SHA; для не-Git источника —
неизменяемую версию или дату снимка вместе с контрольной суммой. Одной даты недостаточно
для сравнения содержимого. Для агентов добавляйте отдельные строки с этими же полями.
В SDW сохраняйте подкаталоги `docs/`, `templates/`, `examples/`: путь к процессу —
`.agents/references/software-development-workflow/docs/workflow.md` (аналогично для Claude).

Реестр описывает проектные копии. Глобальные копии могут иметь другую ревизию;
не заменяйте здесь SHA после одного лишь глобального обновления. Версии CLI Graphify
и Orca фиксируйте отдельно в `MANUAL.md`: это не ревизии их навыков. Заполненный
и проверенный реестр получает `status: "current"`; незаполненные строки не подтверждают установку.

## Проверка набора

Проверка свежести выполняется агентом по запросу: сравнение ревизий источников
с колонкой «Ревизия», фактическое наличие `SKILL.md` каждого навыка в обоих
каталогах и наличие файлов агентов/референсов по указанным путям. Найденные
неучтённые пользовательские материалы перечислите отдельно; не удаляйте их автоматически.
