# Работа с репозиторием Go Product Platform

Это исходники платформы: handbook, инструкции, шаблоны и распространяемые навыки.
Это не целевой продукт. Не запускать bootstrap продукта и не создавать здесь
product.yaml, engineering.yaml, целевое приложение или структуру docs продукта
без соответствующего запроса. Сохранять существующие незакоммиченные изменения.

При правке контрактов согласовывать handbook, шаблоны, bootstrap/manager,
справочники установки, README и CHANGELOG. Ссылки навыков должны работать после
переноса в проектные каталоги. Не изменять глобальные навыки без отдельного запроса.
Отвечать на русском. Проверки и обслуживание этого репозитория — в MANUAL.md.

## graphify

- Проектный навык: `.agents/skills/graphify/SKILL.md` (для Claude также
  `.claude/skills/graphify/SKILL.md`). Перед работой с графом прочитать навык.
- Граф относится к исходникам этой платформы, включая `platform/skills/`,
  handbook, references и templates. Установленные копии `.agents/`/`.claude/`
  и результаты `graphify-out/` исключены из анализа.
- Перед вопросом о связях документов проверить наличие и актуальность графа:
  manifest, изменения/удаления/новые файлы, pending-маркеры. Выполнить
  `graphify query "<вопрос>" --budget 2000`, затем проверить найденные исходники.
  Для связи двух сущностей — `graphify path`, для раздела — `graphify section`.
  INFERRED — подсказка, а не доказательство факта.
- Этот репозиторий преимущественно документный: после изменения Markdown/YAML
  выполнять семантический `/graphify . --update --directed` через навык (в Codex — `$graphify`).
  `graphify update .` обновляет AST и не заменяет анализ документов. Хуки и watcher
  могут лишь отметить необходимость семантического обновления.
- Если граф отсутствует, построить его полным циклом навыка с `--directed`, сохраняя направления ссылок. При невозможности
  обновить явно сообщить ограничение и использовать точечный поиск; не выдавать
  устаревший граф за актуальный. Не удалять pending ради зелёного статуса.
- Граф, кеш и отчёты локальны и игнорируются Git. В новом clone/worktree граф
  строится заново; инструкции установки, команды и ограничения — в MANUAL.md.
