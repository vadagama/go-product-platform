# Работа с репозиторием Go Product Platform

Это исходники платформы: handbook, инструкции, шаблоны и распространяемые навыки.
Это не целевой продукт. Не запускать bootstrap продукта и не создавать здесь
product.yaml, engineering.yaml, целевое приложение или структуру docs продукта
без соответствующего запроса. Сохранять существующие незакоммиченные изменения.

При правке контрактов согласовывать handbook, шаблоны, bootstrap/manager,
справочники установки, README и CHANGELOG. Ссылки навыков должны работать после
переноса в проектные каталоги. Не изменять глобальные навыки без отдельного запроса.
Отвечать на русском. Проверки и обслуживание этого репозитория — в MANUAL.md.

## Анализ кода и документации

Используйте codebase-memory-mcp из корня текущего дерева. После изменения кода или документов обновите индекс через `index_repository`. Выберите проект по пути в `list_projects`, найдите символ или раздел через `search_graph` и сверьте найденные связи с исходниками. Если инструмент недоступен или покрытие неполно, используйте `rg` и укажите ограничение. Команды и проверка индекса приведены в MANUAL.md.
