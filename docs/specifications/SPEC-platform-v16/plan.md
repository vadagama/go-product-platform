# План v16

## Вертикальные срезы

1. Инициализация Git-документации и создание SPEC/архитектурных артефактов.
2. Последовательные этапы, фиксация входов, зависимости и завершение срезов.
3. Исполнение проверок, свежесть доказательств, независимое ревью и финальный gate.
4. Миграции, упаковка CLI, профили навыков и handbook v16.

## Зависимости

Срезы реализуются последовательно; проверка финального кандидата зависит от общего
контракта метаданных, а миграция — от готовой инициализации. Документация основана
на фактически реализованном интерфейсе CLI. Никакой глобальной установки и релиза.

## Проверки

Регрессионный набор `python3 -m unittest discover -s tests -v` в одноразовых Git-репозиториях.
Независимое ревью кода, исправления и тесты найденных обходов; пересборка handbook
через `uv run --with beautifulsoup4 python build.py`, проверка локальных ссылок/HTML-якорей.
