# Решение

Скилл оркестрирует настройку агентом по handbook, вместо универсального
генератора, который перетирал бы разные существующие продукты. CLI выдаёт требования
профиля через init --setup --json. Агент создаёт недостающие файлы, выбирает совместимые
версии и готовит JSON с argv/cwd для установки и проверок. init --setup-plan применяет
одобренный план, устанавливает отсутствующие выбранные навыки и запускает readiness.

Readiness — отдельный модуль стандартной библиотеки. Каждый обязательный компонент
имеет реальные файлы и исполняемые проверки. Проверки запускаются заново; состояние
«готово» не кэшируется. Команды плана — доверенный код продукта, как Makefile;
не использовать планы из недоверенных PR. Секреты поступают через окружение.

Скиллы сохраняются в снимках по содержимому, runtime указывает на установленный
набор. install-cli регистрирует скилл. Совместимость v17 и offline-init сохраняются.

После уточнения пользователя основной интерфейс — короткий вызов и последовательный
опрос в чате. Сценарий и ветвления вынесены в references/questionnaire.md глобального
скилла. CLI остаётся внутренним инструментом агента, терминальный wizard — запасным
интерфейсом. Ни ввод JSON, ни техническое имя профиля не входят в обязательные
действия пользователя. До принятия конкретного плана — только чтение разрешённых
источников. Ответы учитываются в рамках текущего чата и существующей конфигурации.
