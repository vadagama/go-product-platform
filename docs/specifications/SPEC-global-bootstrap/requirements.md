# Глобальная установка продукта через ADE

Пользователь вызывает `$go-platform-bootstrap` в любом доверенном Git-продукте
из Codex, Claude Code, Zed или Orca с поддержкой глобальных Agent Skills.
Агент подготавливает продукт по выбранному профилю, сохраняя существующий код.

- AC-01: install-cli регистрирует глобальный скилл в обоих каталогах;
  имя go-platform-bootstrap и команды сохраняются. Чужие файлы сохраняются.
- AC-02: скилл запускает собственную установленную копию CLI без PATH и исходного клона.
- AC-03: подготовка покрывает workflow, структуру, выбранные глобальные навыки,
  инструменты, зависимости и запускаемый каркас; конкретные пути адаптируются к продукту.
- AC-04: машиночитаемый план содержит профиль, команды установки и проверки каждого
  обязательного компонента; выполнение требует одобрения плана, ошибки останавливают работу.
- AC-05: doctor --ready выполняет свежие проверки и отклоняет пустую активацию,
  пропущенные компоненты, отсутствующие файлы/инструменты и неуспешные команды.
- AC-06: init --offline остаётся восстановлением материалов без сети и глобальных записей.
- AC-07: после глобальной установки достаточно запроса «Подготовь этот проект к
  разработке» с вызовом go-platform-bootstrap в целевом продукте. Агент проводит
  последовательный опрос в чате, сам подбирает профиль и составляет конфигурацию.
  Пользователь не вводит команды CLI/JSON и не указывает профиль заранее.
  Итоговый конкретный план согласуется один раз до записей и установок.
  Нативный синтаксис вызова зависит от ADE; собственный slash-parser не добавляется.

Установка самого скилла выполняется из доверенного набора один раз. Регистрация
в каталогах не доказывает поддержку discovery конкретной конфигурацией ADE.
Credentials, решения об архитектуре и выпуске не выдумываются. Не устанавливать
этой задачей платформу в реальную домашнюю папку разработчика.
